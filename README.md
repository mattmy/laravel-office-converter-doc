# Laravel Office Converter documentation

English and Traditional Chinese documentation for
[`mattmy/laravel-office-converter`](https://github.com/mattmy/laravel-office-converter).

## Local development

```bash
npm install
npm run docs:dev
```

Node.js 24 or later is required.

## Production build

```bash
npm run docs:build
npm run docs:preview
```

GitHub Pages URL:

```text
https://mattmy.github.io/laravel-office-converter-doc/
```
