# 效能與安全

## 執行環境

轉換是同步操作，每次都會啟動設定的執行檔。套件負責驗證輸入與輸出、處理逾時，以及清理自己的
暫存檔案。沙箱、LibreOffice 使用者設定檔、巨集、網路權限與作業系統資源限制由應用程式自行管理。

逾時只保證停止套件直接管理的程序，不保證終止所有衍生程序。

## 記憶體與暫存磁碟

- 每個來源都會複製至獨立的暫存資料夾。
- `fromContent()` 的輸入字串與 `output()` 的完整輸出會占用 PHP 記憶體。
- 只需儲存時，使用 `storeAs()` 串流寫入 Storage，避免將完整輸出載入記憶體。
- `max_output_bytes` 在轉換完成後才檢查，不限制轉換期間使用的磁碟空間。

請依檔案大小與同時轉換的數量，規劃記憶體、暫存磁碟空間及程序數量。

## 格式驗證的限制

套件會檢查基本格式結構，但通過驗證不代表檔案安全。轉換也不保證完整保留版面、字型、公式、
巨集、連結、動畫或圖片；PDF 轉換不提供 OCR 或文件結構重建。

上線前，請用實際會接收的代表性檔案測試，涵蓋常見的語言、版面、字型與公式。

## 路徑與隱私

只傳入應用程式已授權讀取的本機路徑。避免將檔案內容、敏感檔名、伺服器路徑或未移除敏感資訊的
程序輸出寫入紀錄。儲存的轉換結果也須套用應用程式既有的存取權限與保存期限。
